TaskManagementSystem (Business & Booking Management):
Developed a full-stack mobile application integrated with a WhatsApp bot to automate and track business bookings. Seamlessly syncs customer bookings from WhatsApp directly into a MySQL database managed via phpMyAdmin, displaying them instantly on an interactive Kanban board control panel secured by a Role-Based Access Control (RBAC) system.
Technologies Used:
Python, TypeScript, JavaScript, HTML5, CSS3, JSON, React Native, Node.js, MySQL, Expo Go, phpMyAdmin, ERD & Flowcharts, RBAC.
